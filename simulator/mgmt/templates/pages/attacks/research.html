Vulnerability research console

Reproduce bounded experiments from a terminal, then inspect the evidence below. This page never launches a simulator process.

All scenarios
Flight and NATS experiments use a run-owned loopback broker and an X500 vehicle in Gazebo. Camera observation runs separately in an isolated local Gazebo partition without NATS or the Antoine controller. Use test keys and isolated runs only; these results do not cover remote access or physical aircraft.

Watch a swarm

Live 3D: from a terminal in the repository root, run make swarm-live. Gazebo opens while two drones fly; keep that terminal open until the run finishes. For three or five drones use make swarm-live ANTOINE_SWARM_SIZE=3 or =5.

Scripted behaviours: choose lanes, column, vee, rendezvous, or split with ANTOINE_SWARM_BEHAVIOR, or use make swarm-vee, make swarm-rendezvous, or make swarm-split. Each vehicle receives its own fixed waypoint list before launch; the page reports whether final Gazebo poses matched that plan. This is not live formation control or dynamic collision avoidance.

MAVLink telemetry: make swarm-bridge starts one local bridge per drone and checks per-vehicle MAVLink telemetry, checksums, and system-ID isolation. It is a read-only fan-out check: bridge commands do not steer the Gazebo swarm.

After the flight: this page lists saved runs below. Choose View swarm trajectory to inspect the measured top-down paths, or open the run's evidence manifest for integrity details.

The live Gazebo view is 3D. The saved trajectory is a static X/Y plot and does not show altitude or animate the flight. On a headless machine, use make swarm-flight and inspect the saved plot here.

Research report

Each run manifest lists SHA-256 digests for public evidence artifacts. Verify one with uv run --project research python research/verify_evidence_manifest.py RUN_DIR. CSV export checks those digests and records a separate run classification. Classification also requires matching pre/post source, input, run ID, and profile snapshots. This detects evidence that changed after manifest creation; the local manifest is unsigned and does not attest who created the evidence or which binaries were loaded. Private test keys, actuation sequence files, and launcher logs are not served.
